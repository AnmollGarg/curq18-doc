# Frequently Asked Questions (FAQs)

Frequently asked questions about user accounts, application access levels, company assignments, and security settings in CURQ 18.

---

### 1. Where do administrators configure user access levels?

Navigate to **Settings → Users & Companies → Users**. Select an existing user (or click **New** to create one) and configure their application access levels under the **Access Rights** tab.

---

### 2. What is the difference between an Internal User and a Portal User?

An **Internal User** is an employee who has access to backend CURQ applications, menus, and business records based on their assigned roles. A **Portal User** is an external contact (such as a customer or vendor) who can only view their own documents (such as quotations, invoices, or delivery orders) through the front-facing web portal. Portal access is managed directly from partner cards in **Contacts → Actions → Grant portal access**.

---

### 3. How do I change a user's role from standard user to administrator for an app?

Open the user's card under **Settings → Users & Companies → Users**. In the **Access Rights** tab, locate the application category (such as **Sales** or **Accounting**) and select the appropriate role from the dropdown menu (for example, change from **User** to **Administrator**). Click **Save**.

---

### 4. How do I grant a user access to multiple companies?

Open the user record in **Settings → Users & Companies → Users**. In the **Access Rights** tab, locate the **Multi Companies** section. Select the companies the user is permitted to work in under **Allowed Companies**, and select their primary default branch under **Default Company**.

---

### 5. Why is a newly invited user unable to access a specific menu or app?

Verify that the user has an active access level assigned for that app in their **Access Rights** tab. If the role is set to empty or none, the corresponding menu will not appear in their main navigation bar. Also ensure the user has completed their account invitation and password setup.

---

### 6. Why is an application category missing from the Access Rights tab?

The **Access Rights** tab dynamically renders controls based on installed modules. If an application category (such as Point of Sale, Project, or Events) does not appear on the user card, check whether the corresponding module is installed under the main **Apps** menu. Installing an application automatically exposes its access rights on this tab.
