# Roles and Permissions

Manage user accounts, assign application access levels, configure multi-company visibility, and maintain account security in CURQ 18.

## Standard Role Assignment and User Management
With Roles and Permissions, administrators control which business applications and operational features each team member can access. Create user accounts, assign functional access levels across installed apps (such as Sales, CRM, and Accounting), and ensure employees have the exact permissions required for their daily responsibilities.

## Multi-Company Access and Account Security
Manage organizational access by assigning authorized companies and setting default branch workspaces for each user. Control user invitation workflows, enforce password security policies, configure two-factor authentication (2FA), and maintain account security.
